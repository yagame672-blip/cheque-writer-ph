# Cheque Writer PH – Download Page

A professional download landing page for **Cheque Writer PH**, deployed on Vercel.

The page auto-fetches the latest release from GitHub and updates the download link automatically.

## 🚀 Deployment

- **Live Landing Page:** [cheque-writer-ph.vercel.app](https://cheque-writer-ph.vercel.app)
- **Admin Analytics Dashboard:** [cheque-writer-ph.vercel.app/admin.html](https://cheque-writer-ph.vercel.app/admin.html)

## 📦 How the Download Works

1. The installer ZIP is hosted as an official **GitHub Release asset** on `yagame672-blip/cheque-writer-ph`.
2. The `main.js` automatically fetches the latest release from the GitHub API in real time.
3. The download button always delivers the latest verified release.
