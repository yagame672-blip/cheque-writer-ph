Simulan sa tatlong hakbang

Mga karaniwang tanong

May lumabas na "Windows protected your PC" pagbukas ng installer.

Normal ito sa bagong app na wala pang code-signing certificate. I-click ang More info, tapos Run anyway.

Kailangan ba ng internet?

Hindi sa paggawa at pag-print ng tseke. Nasa PC mo lang naka-save ang mga record mo. Internet lang ang kailangan kapag magda-download ng update.

Kailangan ba ng admin access para ma-install?

Hindi. Sa sariling folder ng Windows user mo ito naka-install, kaya hindi na kailangan ng IT admin.

Saan makikita ang Machine ID?

Nasa kanang bahagi ng main screen ng app, may Copy button sa tabi. Kailangan ito sa activation pagkatapos ng trial.
